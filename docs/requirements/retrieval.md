# Retrieval Requirements

The retrieval system should support ecommerce image gallery search with text, image, and image+text queries.

Required capabilities:

- build stable product and subcategory groupings from local catalog/image data
- evaluate text-to-image retrieval with TopK metrics
- evaluate image-to-image and image+text-to-image retrieval
- combine multiple recall routes
- apply reranking or filtering and report before/after metrics
- support reproducible out-of-domain web retrieval smoke checks

Requirement summaries in this directory are generalized from external specifications and should not reference local source files.
